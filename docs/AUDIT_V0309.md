# Audit V0.309 — Intégration runtime réelle

Le contrôle d'identité s'exécute avant le flux conversationnel normal de table/cuisine. Une piste inconnue déclenche une demande d'identité ; sa réponse est résolue contre le foyer et seule une correspondance confirmée est injectée dans le runtime actif. Les pistes différentes restent indépendantes et aucune attribution n'est faite en cas d'ambiguïté.
