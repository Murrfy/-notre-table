# Audit V0.295

Checkpoint **0.295.0**.

V0.295 utilise les anniversaires déjà enregistrés par LIA sans créer un nouveau système de rappel ou d’automatisation.

- LIA calcule le prochain anniversaire à partir du jour/mois stocké.
- Une personne peut être signalée une fois pendant la fenêtre des sept jours précédents puis une fois le jour même.
- L’âge n’est jamais annoncé ni nécessaire au fonctionnement.
- Le 29 février est ramené au 28 février les années non bissextiles afin de conserver une présence annuelle.
- L’intervention reste informative et conversationnelle : aucune écriture de rappel, liste, planning, réservation ou achat n’est déclenchée sans demande explicite.
- Une intervention anniversaire bloque une nouvelle question de profil dans le même moment calme afin d’éviter deux initiatives successives.
- La parole passe par le moteur de guidage contextuel LIA existant et non par un assistant parallèle.
