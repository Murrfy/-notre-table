# Audit V0.308 — Orchestration d'identification

## Portée
- Déclencher l'identification d'un locuteur inconnu à table ou en cuisine.
- Résoudre sa réponse contre le roster familial.
- Confirmer, clarifier ou conserver l'absence d'attribution.

## Garde-fous
- La piste vocale à identifier est conservée explicitement.
- Les doublons ne sont jamais départagés au hasard.
- Un nom absent du foyer ne reçoit aucune mémoire personnelle.
- Une question urgente peut être traitée avant l'identification.

## Validation
À valider par le workflow GitHub Validate Notre Table sur le SHA exact de la PR avant fusion.
