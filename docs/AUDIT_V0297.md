# Audit V0.297

Checkpoint **0.297.0**.

LIA réutilise maintenant un goût familial explicitement appris lorsqu’un membre répond « Fait maison » dans Message famille. La préférence reste une piste conversationnelle et n’est jamais transformée en décision de menu.

Le plat préféré vient uniquement du profil progressif enregistré en V0.296. Un vote ponctuel n’écrit aucune préférence. Le comportement fonctionne aussi lorsque l’écran Message famille est fermé grâce au moniteur de décisions familiales existant, qui recharge les faits confirmés avant d’émettre l’événement LIA.

Aucun nouvel état persistant, moteur d’assistance, pipeline vocal ou écriture automatique n’est ajouté.
