# Mise à jour stratégie — 13 septembre 2026

## Changement majeur vérifié
Le site officiel de Mealime annonce une fermeture le **21 octobre 2026**.

Conséquence : la stratégie « attaquer Mealime » du cahier des charges n'est plus la bonne formulation. Notre Table doit plutôt :

1. capter les familles qui devront remplacer leur outil de planification ;
2. accentuer le différenciateur foyer / collaboration temps réel ;
3. rendre l'import de recettes particulièrement simple afin de réduire le coût de migration ;
4. benchmarker en priorité les concurrents qui restent actifs, notamment AnyList, Paprika et Samsung Food ;
5. ne jamais promettre de migration Mealime automatique tant qu'un format d'export officiel exploitable n'a pas été vérifié.

## Benchmark produit retenu
- AnyList : partage familial, recettes, calendrier repas, import web et passage recette → courses.
- Paprika : bibliothèque personnelle, import web, planification et synchronisation.
- Mealime : référence historique pour le flux planifier → courses → cuisiner, mais fermeture annoncée.

## Effet sur le roadmap
Priorité renforcée à :
- import URL ;
- import photo/OCR après backend sécurisé ;
- réutilisation d'une semaine ;
- listes de courses robustes hors-ligne ;
- synchronisation familiale native.
