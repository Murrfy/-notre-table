# Audit V0.11 — Profil et invitation

## Implémenté
- Nom affiché modifiable par l'utilisateur.
- Le nom est utilisé dans le foyer, le choix du cuisinier et « qui mange ? » après rechargement.
- Validation 2 à 60 caractères côté application ; plafond 60 caractères côté base.
- Invitation partageable via la feuille de partage native après génération du code à 6 caractères.
- Aucun service tiers ni nouvelle dépendance nécessaire.
