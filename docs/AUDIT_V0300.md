# Audit V0.300

Checkpoint **0.300.0**.

LIA peut désormais enrichir progressivement sa connaissance de la famille avec des questions très courtes et concrètes, uniquement pendant un vrai blanc détecté par le pipeline d’écoute déjà actif. Le mode table partagé bloque ces questions ; un moment de cuisine silencieux reste possible. Une seule question est posée, puis LIA se tait.

Les premiers faits rapides sont : couleur préférée, couleur de cheveux, parfum et shampoing. Les réponses sont explicites, peuvent être reportées ou refusées, et sont enregistrées dans la mémoire relationnelle existante avec l’identité stable du membre, sans nouvelle table parallèle. Les faits restent privés du foyer par défaut.

Après enregistrement, le même moteur conversationnel de LIA peut rebondir brièvement avec chaleur et répondant. Pour une marque ou un produit, LIA ne doit mentionner un détail externe que si elle en est réellement sûre ; elle ne doit jamais inventer une gamme, un produit ou une histoire pour remplir le silence.
